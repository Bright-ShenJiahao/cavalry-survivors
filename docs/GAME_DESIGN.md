# 骑兵幸存者：冲锋与魔法 · Cavalry Survivors · 騎兵サバイバーズ —— 设计总表

- ✅ 中文名：**骑兵幸存者：冲锋与魔法**（2026-11-05）。英文、日文副标题 ⏳ 待定。
- ✅ 宣传语：「穿越历史骑兵战场，冲锋、割草，在战火中觉醒魔法。」/ *Charge through history's greatest cavalry battles — and awaken the magic within.*

> 状态：讨论中，逐项定稿。✅ = 已定，⏳ = 待定 / 待做。结构参考异世界幸存者（sanguoxingcunzhe 仓库 docs/GAME_DESIGN.md）。

## 1. 设定
- ✅ 主角是**穿越者**，骑马冲进世界各地著名的骑兵战役（中国、日本、欧洲……）。
- ✅ 主角**不受时代限制**；小兵、敌人、战场**严格按历史**。
- ✅ 第一章：**高加米拉（前 331 年）**，最终 Boss 是大流士的战阵。
- ✅ 以后可以加入**魔幻元素**，全部从穿越者身上来（「系统」能力、神器卡、后期神话章节）。卡牌系统预留新卡类。

## 2. 核心手感
- 只有方向操作（摇杆 / WASD）。马有惯性：加速慢，高速时转弯半径大，往马屁股方向推是刹车。
- 伤害主要靠马速：0 速 0.5 倍，满速 2 倍。冲锋速度（70%）以上撞到小兵直接撞飞。下坡可以超速到 130%。
- 带亲卫骑兵组成楔形阵一起冲。
- ⏳ 冲锋线加缓冲：70% 以上进入冲锋，60% 以下才退出。
- ⏳ 伤害按**绝对速度**算（以标准马满速为基准），不按自己马的极速归一化。烈马上限高；稳马靠少掉速、回速快。

## 3. 一局的结构
- ✅ **一局 15 分钟**（以后章节 12～18 分钟，按战役规模定）。
- ✅ **3:00 小 Boss 麻葛**（波斯祆教祭司）出现，目标 3:30 左右打死 → 「穿越者·系统觉醒」→ 解锁法术。
  - 历史依据：库尔提乌斯记载，波斯大军行军时，银祭坛上的圣火走在最前面，麻葛唱着颂歌随行。magic 一词就来自 magus。
  - 白袍高冠，身边是燃着圣火的银祭坛，周围一圈不死军护卫。
  - 能力：颂歌（圣火附近的兵变快变硬）、火罐（扔燃烧油罐）、护火（护卫被打光之前他本人受伤减半）。
  - **不逃跑**，留在原地打死为止。拖得越久，颂歌加强的兵越多。
- ⏳ 怪物和时间线以后再设计。参考节奏：0～3 分轻步兵 → 3 分麻葛 → 敌骑 → 镰刀战车 → 10 分贝苏斯侧翼 → 12～14 分战线压上 → 14～15 分大流士战阵。

## 4. 局内成长
- ✅ 杀怪掉经验宝石，升级三选一；每升 3 级送 1 次重抽，可以跳过。
- ✅ **格子：专属 1 + 兵器 3 + 法术 3 + 被动 6**。格子满了只出已有卡的升级。
- ✅ 兵器、法术都是 5 级，满级有质变。
- ✅ **法术**：开局锁着。打败麻葛后**一定给 1 个**，从全部法术里随机出 3 个三选一；之后正常升级时也会随机出现。每局都要重新觉醒。
- ✅ **被动 = 战法 + 祝福**，混在同一个池子，卡上用标签区分：
  - 战法：满足骑乘条件就触发，改变打法。
  - 祝福：纯数值，管人和部曲。
- ✅ 宝箱：精英掉落，老虎机开奖。⏳ 改成转出 3 张已有卡、选 1 张升 1 级（原来是随机 +1 / 3 / 5）。

### 4.1 专属：骑枪 ✅（已实装）
- 金框，不占格子，开局就有。
- 只刺**正前方 100°**（左右各 50°），枪永远往马头方向刺。现实中长枪只能往前刺，不能 360° 挥。
- 攻击范围 110（约人马高度 2 倍），每 0.6 秒最多刺一次。伤害 14 × 速度倍率。
- 撞人保留。
- Lv2 伤害 +30% · Lv3 枪更长，攻击范围 +25% · Lv4 出枪更快 · Lv5「贯阵」：冲锋速度下一枪贯穿前方 300 一条线。

### 4.2 亲卫攻击 ✅（已实装）
- 跑起来（30% 以上）：和主角一样骑枪前刺 100°，攻击范围 100。
- 停下来：拔刀小范围环形砍，半径 45（伙伴骑兵带佩剑）。

### 4.3 兵器 ⏳ 暂定（2026-11-05）
- **长柄武器做成人物专属**（手里只能握一把长柄，且画在人物精灵图上）；**副武器进卡池**（挂在马鞍或腰间，自动攻击的特效，不用画在人物身上）。
- 局外拥有约 10 把副武器，出发前固定带 5 把，局内最多装 3 把。每把都要有独有的特点。
- ✅ **原则（2026-11-05）**：名字、说明、历史出处按真实写；**攻击形状学吸血鬼幸存者**：大、清楚、一眼看懂、一下扫一片。**不要以人物为中心、按兵器真实长度判定**（那样只能打到贴身的人，又小又弱）；要像吸血鬼那样发散：甩出去、抛出去、在远处落下、在地上留下范围、向外扩散。

### 4.3.1 硬控规则 ✅（全局，已实装）
- 倒地、摔倒、晕都算硬控。**同一个敌人 3 秒内只能被硬控一次**，之后再碰到只受伤、减速。
- 被连锁撞倒的人只倒一次，不会因为倒在蒺藜等东西上再被触发。
- Boss 和精英不会被硬控，只受伤、减速，减速最多 30%。

### 4.4 被动·战法（候选，都是骑兵真实战术）
| 战法 | 触发 | 效果 |
|---|---|---|
| 冲锋号 | 冷却好后，下一次越过冲锋线 | 全队 3 秒极速，撞人不掉速 |
| 铁蹄 | 冲锋中第一次撞到人 | 落点震地，周围小兵倒地 1 秒 |
| 部曲齐射 | 调头（回马）时 | 亲卫朝追兵方向齐射，落下一片箭雨 |
| 楔形阵 | 有 3 个以上亲卫并且在冲锋 | 亲卫收紧成楔形整队撞，正面撞击范围变宽（伙伴骑兵在高加米拉的阵型） |
| 佯退 | 背对敌人跑满 3 秒 | 追兵阵型散乱、减速，下一次回冲伤害 +50%（斯基泰、蒙古） |
| 威压 | 一次冲锋撞飞 5 人以上 | 附近敌人恐慌，四散逃跑 2 秒 |
| 蓄势 | 保持冲锋速度 | 伤害每秒 +10%，最多 +30% / 45% / 60%，掉到 60% 以下清零 ✅ 已实装 |
| 回马 | 1.5 秒内马头转过 150° | 之后 2 / 2.5 / 3 秒伤害按满速算 ✅ 已实装 |
- 旋风斩删掉（原地转圈不像骑兵，和流星锤、亲卫拔刀重复）。

### 4.5 被动·祝福
- 力量、体魄（生命上限 +15% / 级）、急速、再生、部曲（亲卫 +1，⏳ 上限提到 8～10 骑）、精锐。
- ✅ 局内**不改马的手感**（速度、转向）。疾驰、驭术已删除。

### 4.6 割草感 ⏳
- 撞飞连锁：所有冲锋撞飞的人都会砸倒身后的人。
- 小兵更多、更脆。
- 部曲能滚到 8～10 骑，整队楔形冲锋。
- 战法做成大场面（震地、箭雨、溃逃）。

## 5. 局外
- 货币：军功（⏳ 按冲锋撞飞的人数奖励，而不是按存活时间）。
- **卡组**：兵器自己选（约 10 带 5）；被动锁定 2 个必出 + 随机补到 8 个；**法术局外只能在图鉴看，不能搭配**。
- **马厩**（✅ 一匹马，所有人物共用）：
  - **调教方向** ✅ 已实装：主界面「马厩」里一根滑块，稳 ↔ 烈（吸附极稳 / 中 / 极烈三个刻度），存在本机，免费随时改，独占手感。极稳：速度 -12%、加速 -10%、转向和刹车 +20%；极烈反之。亲卫同样适用。伤害按绝对速度算。
  - **训练**：花军功，只练体质：冲击（撞击伤害 + 撞人少掉速）、耐力（生命）。
  - ⏳ 觉醒特性（踏泥、俯冲、铁骨、识途……）后做。
  - ✅ 马具 3 槽，简单版，后做：马铠（无 / 皮甲 / 铁甲）、马鞍（轻鞍 / 高桥鞍）、蹄铁（普通 / 防滑）。**只有铁甲改外观**，每个人物多一张披甲版人马一体图。
- **分层原则** ✅：每种数值只归一个地方管。
  - 局外（马厩）管「马跑多快」；局内管「跑得快有什么用」。
  - 同一种数值局外局内都加（如生命）视为正常叠加；局内改成按百分比加。
- 人物：⏳ 首发 2～4 个。每人自带一匹马（人马画在一张图里，所以不换马），特色 = 1 把专属兵器 + 1 个特性。
- 图鉴、成就、章节进度（卡组和马带到下一章）。
